# Módulos

Cada módulo do framework está documentado nesta seção.

- `auth/`: Autenticação e backends
- `models/`: Modelos e ORM
- `views/`: ViewSets e APIViews
- `routing/`: Roteamento e URLs
- `permissions/`: Sistema de permissões
- `realtime/`: WebSocket e SSE
- `messaging/`: Kafka/RabbitMQ/Redis
- `admin/`: Interface administrativa

> Nota: ainda não há arquivos específicos de módulo; use os docs gerais vinculados na raiz.
