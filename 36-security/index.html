Security Headers¶

Enable via middleware:

# src/settings.py
class AppSettings(Settings):
    middleware: list[str] = [
        "security_headers",
        # ...
    ]

Default headers:

Header Value Purpose
X-Content-Type-Options nosniff Prevent MIME sniffing
X-Frame-Options DENY Prevent clickjacking
X-XSS-Protection 1; mode=block XSS filter
Referrer-Policy strict-origin-when-cross-origin Control referrer

Custom Headers¶

middleware = [
    ("security_headers", {
        "headers": {
            "X-Content-Type-Options": "nosniff",
            "X-Frame-Options": "SAMEORIGIN",
            "Content-Security-Policy": "default-src 'self'",
        },
        "enable_hsts": True,
        "hsts_max_age": 31536000,
    }),
]

HSTS¶

Enable for HTTPS:

middleware = [
    ("security_headers", {
        "enable_hsts": True,
        "hsts_max_age": 31536000,  # 1 year
    }),
]

CORS¶

# src/settings.py
class AppSettings(Settings):
    # Allowed origins (empty = none)
    cors_origins: list[str] = ["https://app.example.com"]

    # Allow credentials (cookies, auth headers)
    cors_allow_credentials: bool = True

    # Allowed methods
    cors_allow_methods: list[str] = ["GET", "POST", "PUT", "PATCH", "DELETE"]

    # Allowed headers
    cors_allow_headers: list[str] = ["Authorization", "Content-Type"]

Production Warning¶

Never use "*" in production:

# BAD - allows any origin
cors_origins: list[str] = ["*"]

# GOOD - explicit origins
cors_origins: list[str] = [
    "https://app.example.com",
    "https://admin.example.com",
]

validator = PasswordValidator(

Use strong hashers:

    # Recommended: Argon2
    password_hasher: str = "argon2"  # pip install argon2-cffi

    # Alternative: BCrypt
    # password_hasher: str = "bcrypt"  # pip install bcrypt

SQL Injection Prevention¶

The framework uses SQLAlchemy ORM with parameterized queries:

# SAFE - parameterized query
users = await User.objects.using(db).filter(email=user_input).all()

# SAFE - QuerySet API
users = await User.objects.using(db).filter(
    name__contains=search_term
).all()

Never use raw SQL with user input:

# DANGEROUS - never do this
query = f"SELECT * FROM users WHERE email = '{user_input}'"

# SAFE - use parameters
from sqlalchemy import text
result = await db.execute(
    text("SELECT * FROM users WHERE email = :email"),
    {"email": user_input}
)

Input Validation¶

Use InputSchema¶

from strider.serializers import InputSchema

class UserInput(InputSchema):
    email: str
    name: str
    # Por padrão extra="ignore" (campos desconhecidos ignorados)
    # str_strip_whitespace=True limpa strings
    # Para rejeitar campos extras: model_config = ConfigDict(extra="forbid")

Validate All Input¶

from strider.validators import (
    EmailValidator,
    MinLengthValidator,
    MaxLengthValidator,
)

class UserViewSet(ModelViewSet):
    model = User

    field_validators = {
        "email": [EmailValidator()],
        "name": [MinLengthValidator(2), MaxLengthValidator(100)],
    }

Rate Limiting¶

Not built-in. Implement with middleware:

from strider.middleware import ASGIMiddleware
from strider.exceptions import TooManyRequests

class RateLimitMiddleware(ASGIMiddleware):
    name = "RateLimitMiddleware"

    async def before_request(self, scope, request):
        client_ip = request.client.host

        if await self.is_rate_limited(client_ip):
            raise TooManyRequests(
                message="Too many requests",
                retry_after=60
            )

        await self.increment_counter(client_ip)
        return None

CSRF Protection¶

Admin panel uses SameSite=Lax cookies:

response.set_cookie(
    key="admin_session",
    value=session_key,
    httponly=True,
    samesite="lax",
    secure=True,  # HTTPS only
)

For API endpoints, use JWT tokens instead of cookies.

Secrets Management¶

Environment Variables¶

# .env (never commit)
SECRET_KEY=your-256-bit-secret-key
DATABASE_URL=postgresql+asyncpg://user:pass@host/db

Never Commit Secrets¶

# .gitignore
.env
.env.local
.env.production
credentials.json
*.pem
*.key

Validate in Production¶

from strider.auth import validate_auth_configuration

issues = validate_auth_configuration()
if issues:
    for issue in issues:
        print(f"WARNING: {issue}")

Sensitive Data¶

Exclude from Responses¶

class UserOutput(OutputSchema):
    id: int
    email: str
    name: str
    # password NOT included

Exclude from Logs¶

middleware = [
    ("logging", {
        "log_body": False,  # Don't log request bodies
        "log_headers": False,  # Don't log headers
    }),
]

Production Checklist¶

  • [ ] SECRET_KEY is unique and secure (256+ bits)
  • [ ] DEBUG is False
  • [ ] CORS_ORIGINS is explicit (no "*")
  • [ ] HTTPS is enforced
  • [ ] HSTS is enabled
  • [ ] Password hasher is Argon2 or BCrypt
  • [ ] Rate limiting is implemented
  • [ ] Sensitive data excluded from logs
  • [ ] .env files not committed
  • [ ] Database credentials are secure
  • [ ] Admin panel has strong authentication
